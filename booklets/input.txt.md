# Project Presentation

The primary objective of this project is to optimize and improve access to medical services through a user-friendly online platform. The system aims to reduce administrative overhead, accelerate medical response times, and enable continuous care through digital channels. The project focuses on providing a distributed, scalable, and modular architecture, ensuring reliability and the ability to easily integrate additional services or technologies in the future.

## System Overview

At its core, the platform allows patients and doctors to create individual profiles, each containing relevant, personal and professional details. For example, patients can include medical histories, allergies, or insurance data, while doctors can list their specialties, office hours, certifications, and experience. A search mechanism enables patients to filter healthcare professionals based on criteria such as location, specialty, or availability. Once a match is found, communication can happen via an integrated chat or ticketing system, ensuring that routine queries and urgent requests alike are tracked efficiently.

Beyond communication, the platform supports file sharing in formats commonly used in healthcare—particularly PDFs, which might include test results, clinical reports, and detailed medical records. This feature allows doctors to review patient documents in advance, enhancing the quality and speed of the consultation process.

Appointments are managed through an online booking system that displays real-time availability for each doctor. Patients can schedule visits or online consultations at their convenience, and doctors can confirm or suggest alternative time slots. Post-consultation, doctors can issue digital prescriptions or other relevant documents that patients can immediately access within their user dashboard.

## User Stories

### Patient Stories

**US1** - As a patient, I want to register on the platform and create a personal profile with my basic information so that I can access all the system's features.

**US2** - As a patient, I want to update my profile with my medical history and insurance details so that my data remains current and useful for consultations.

**US3** - As a patient, I want to search for doctors by specialty, location, availability, and language so that I can find a provider that best matches my needs.

**US4** - As a patient, I want to apply filters (e.g., rating, distance, fee range) and sort search results so that I can quickly narrow down the best options.

**US5** - As a patient, I want to initiate a chat or submit a support ticket to a doctor so that I can ask pre-consultation questions.

**US6** - As a patient, I want to view the history of my chats or tickets with doctors so that I can refer back to previous advice.

**US7** - As a patient, I want to upload my medical documents (lab results, prescriptions, images) so that doctors can review them ahead of appointments.

**US8** - As a patient, I want to book an appointment with a selected doctor by choosing an available time slot so that I can secure a consultation at my convenience.

**US9** - As a patient, I want to view, reschedule, or cancel my appointments so that I can maintain flexibility in my schedule.

**US10** - As a patient, I want to receive and view digital prescriptions and follow-up instructions so that I have ready access to treatment details.

**US11** - As a patient, I want to leave a review and rate a doctor after an appointment so that other patients can make informed decisions.

### Doctor Stories

**US12** - As a doctor, I want to create a detailed professional profile including my specialties, credentials, and experience so that patients can evaluate my qualifications.

**US13** - As a doctor, I want to update my profile and upload supporting documents (certifications, licenses) so that my information remains verified and trustworthy.

**US14** - As a doctor, I want to set my working hours and update my calendar so that patients can book appointments only during my available times.

**US15** - As a doctor, I want to receive notifications for new appointment requests so that I can promptly review and confirm or suggest alternative times.

**US16** - As a doctor, I want to view and manage my upcoming appointments in a calendar view so that I can effectively organize my schedule.

**US17** - As a doctor, I want to receive and reply to patient inquiries via chat or ticket so that I can provide timely advice even before consultations.

**US18** - As a doctor, I want to view and annotate uploaded patient documents so that I can prepare in advance for each consultation.

**US19** - As a doctor, I want to generate and send digital prescriptions and medical reports to patients so that they can quickly access the necessary documentation.

**US20** - As a doctor, I want to see the reviews and ratings left by my patients so that I can understand their feedback.

### Admin Stories

**US21** - As an admin, I want to view, modify, or deactivate user accounts (both patients and doctors) so that I can maintain the platform's integrity.

**US22** - As an admin, I want to verify doctors' credentials and review their submitted documentation so that only qualified professionals are active on the platform.

**US23** - As an admin, I want to monitor system performance and usage metrics so that I can quickly detect and resolve issues.

**US24** - As an admin, I want to configure and update security policies and access permissions so that patient and doctor data remains protected.
